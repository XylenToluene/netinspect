Подключение к кластеру

Вставьте команду oc login — netinspect проверит доступ по токену, найдёт ресурсы Istio и права на чтение.

Параметры подключения

Консоль OpenShift → ваше имя → Copy login command. Поля ниже заполнятся сами.

или вручную

В терминале: oc whoami -t

Токен уходит только на сервер netinspect, хранится в его памяти до конца сессии и не сохраняется в браузере.
